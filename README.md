# Placement Eligibility Portal

A full-stack MERN application for managing student profiles, placement eligibility, and placement drives.

## Features
- Student registration and login
- Admin and student role-based access
- Student profile management
- Placement eligibility checking
- Admin management of companies and students

## Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js
- Tailwind CSS

## How to Run
1. Clone the repository
2. Install dependencies for frontend and backend
3. Configure environment variables
4. Run backend and frontend servers
